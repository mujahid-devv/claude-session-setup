# Worklog

Shared state between Claude sessions. Newest entries first. Facts, not transcripts. Written by `/handoff`, read by `/catchup`.

## Entry format

```
## YYYY-MM-DD HH:MM — <short title>
- Status: in progress | done | blocked | deployed (<env>)
- Branch/PR: <branch>, <PR number or commit sha>
- Changed: <what and where, key files>
- Decisions: <choice made and why>
- Verified: <tests run, how it was checked>
- Next/open: <what remains, risks>
```
